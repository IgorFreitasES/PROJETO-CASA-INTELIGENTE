# ESP32 - Controle do Portão

Primeiro módulo do Projeto Casa Inteligente.

Objetivo

Controlar remotamente o motor Rossi DZ4 Turbo utilizando um ESP32 conectado ao Wi-Fi.

## Hardware

- ESP32 DevKit
- Módulo Relé
- Fonte 5V
- Motor Rossi DZ4 Turbo
