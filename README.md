# PROJETO-CASA-INTELIGENTE
Sistema de automação residencial de baixo custo, utilizando notebook velho, ESP32, cameras IP, sensores e integração web.

## Objetivo

Criar uma central de automação residencial capaz de controlar dispositivos, monitorar ambientes e fornecer informações em tempo real utilizando hardware acessível.

## Hardware Utilizado

* Notebook antigo (Servidor)
* ESP32
* Relé Wi-Fi
* Câmeras IP
* Roteador doméstico
* Sensores diversos

## Software Utilizado

* Node-RED
* MQTT
* Python
* HTML
* CSS
* JavaScript
* GitHub

## Funcionalidades Implementadas

* [x] Servidor Node-RED instalado
* [ ] Comunicação com ESP32
* [x] Relé integrado ao sistema
* [ ] Controle remoto do portão
* [ ] Dashboard residencial
* [ ] Integração com câmeras IP
* [ ] Monitoramento de sensores
* [ ] Notificações para celular

ESP32 → Wi-Fi → Node-RED → Dashboard Web
